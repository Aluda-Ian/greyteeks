Overview

Base URLs, authentication, and environment configuration.

LIVE Production Base URL
https://app.greyteeks.com/api/v1
Real-world traffic. All API calls here result in actual SMS / WhatsApp sends and billing.
SANDBOX Sandbox Base URL
https://sandbox.greyteeks.com/api/v1
Safe testing environment. Messages are never delivered. No charges incurred.
Authentication

All API requests require a Bearer token in the Authorization header. Obtain your key from Settings → API Keys in the Greyteeks dashboard.

# Authorization header format Authorization: Bearer YOUR_API_KEY_HERE # Example curl curl -X GET https://app.greyteeks.com/api/v1/statushttps://sandbox.greyteeks.com/api/v1/status \ -H "Authorization: Bearer sk_live_xxxxxxxxxxxx" \ -H "Content-Type: application/json"
Request Format
All request bodies must be JSON.
Set Content-Type: application/json.
Response Format
All responses return JSON with a consistent status, message, and optional data envelope.
Timeouts
API requests time out after 30 seconds. Implement retry logic for critical workflows.

SMS API Providers

Step-by-step credential extraction and Greyteeks configuration for each supported SMS gateway.

Africa's Talking provides robust, developer-friendly SMS coverage across 10+ African countries with reliable delivery reports.

LIVE Production Endpoint
https://api.africastalking.com/version1/messaging
SANDBOX Sandbox Endpoint
https://api.sandbox.africastalking.com/version1/messaging
Use sandbox username: sandbox. Messages appear in the AT simulator.
Setup Steps
1
Create an account on the Africa's Talking portal. Verify your email and phone number to unlock full access.
2
Create an App: From your dashboard → Apps → Create App. Give it a unique name (e.g., greyteeks-prod). Note the App Username — this is not your login email.
3
Generate an API Key: Inside the app →Settings → API Key → click Generate. Copy and store it immediately (it won't be shown again).
4
Register a Sender ID: Go to SMS → Sender IDs → Request. Provide your business name (e.g., GREYTEEKS). Approval may take 1–3 business days.
5
Configure in Greyteeks: Go to Messaging → SMS → Add Provider, select Africa's Talking and enter:
Greyteeks FieldWhere to FindNotes
API KeyApp → Settings → API KeyRequired
UsernameApp Username (not login email)Required
Sender IDApproved Sender ID stringOptional

WhatsApp API Providers

Official Meta Cloud API and Infobip WhatsApp gateway configuration.

The official Meta Cloud API connects directly to Meta's infrastructure — zero markup, highest reliability, full template management via Meta Business Suite.

LIVE Production
Messages sent to real mobile numbers. Charges apply per Meta's conversation-based pricing model.
SANDBOX Test Phone Numbers
In WhatsApp → Getting Started, Meta provides 5 test recipient numbers. Messages send without real delivery. No charges apply.
Detailed Setup
1
Create a Meta Business Account: Visit Meta Business Suite and set up or link your business account.
2
Create a Meta App: Go to Meta for Developers → My Apps → Create App → Business. Add the WhatsApp product.
3
Generate a Permanent Access Token (critical):
Do NOT use the temporary token from the Getting Started page — it expires in 24 hours and will break your integration.
  • Go to Business Settings → System Users → Add
  • Create a System User, click Generate New Token
  • Select your app, enable whatsapp_business_messaging + whatsapp_business_management
  • Copy and store the token securely — shown only once
4
Extract IDs: From WhatsApp → Getting Started in your app, copy:
  • Phone Number ID — identifies the sending number
  • WhatsApp Business Account ID (WABA ID) — your business account identifier
5
Configure in Greyteeks: Go to Messaging → WhatsApp → Add Provider, select Meta Cloud API:
Greyteeks FieldMeta Value

WABA IDWhatsApp Business Account IDRequired
6
Set up Webhook (for delivery reports & inbound messages):
  • In Meta App → WhatsApp → Configuration → Webhooks
  • Callback URL: https://app.greyteeks.com/webhook/whatsapp/https://sandbox.greyteeks.com/webhook/whatsapp/
  • Verify Token: contact your Greyteeks admin for your unique verify token
  • Subscribe to: messages, message_deliveries, message_reads

WhatsApp Message Templates

Meta requires all business-initiated messages to use pre-approved templates.

Critical — Template Compliance

Per Meta policy, every outbound WhatsApp message initiated by a business must use a pre-approved template. The message body must match the approved template character-for-character. Any deviation will cause delivery failure with a PROVIDER_ERROR.

MARKETING
Promotions, offers, newsletters. User must have opted in. Charged at marketing conversation rate.
UTILITY
Order confirmations, alerts, account notifications. Lower rate than marketing.
AUTHENTICATION
OTPs and verification codes. Lowest rate. Must use the standard OTP template format.
Creating & Submitting a Template
1
In Meta Business Suite → WhatsApp Manager → Message Templates → Create Template
2
Choose Category (Marketing / Utility / Authentication), enter a lowercase underscore Template Name (e.g., order_confirmation), and select a Language.
3
Write the template body using {{1}}, {{2}} for dynamic variables. Example: Hello {{1}}, your order {{2}} has been shipped.
4
Submit for review. Approval typically takes 2–24 hours. You'll receive an email notification.
5
In Greyteeks → Messaging → WhatsApp → Templates → Import. Paste the exact template name and configure variable mappings.
// Sending a template with variables { "provider": "meta", "to": "+254700000001", "template_name": "order_confirmation", "language_code": "en_US", "components": [ { "type": "body", "parameters": [ { "type": "text", "text": "Jane" }, { "type": "text", "text": "ORD-20240415" } ] } ] }

Integration Testing Guide

Best practices for validating your setup before going live.

SMS Testing Checklist
  • Use Africa's Talking sandbox (username: sandbox) to simulate sends
  • Twilio: verify at least one test phone number in console before trial sends
  • Test phone number formatting: always use E.164 format (+254XXXXXXXXX)
  • Check delivery reports via GET /api/v1/delivery-reports/{id}
  • Verify sender_id is approved before bulk sends
WhatsApp Testing Checklist
  • Use Meta's 5 sandbox test recipient numbers during development
  • Confirm hello_world template works before testing your own templates
  • Verify webhook is correctly registered and verify token matches
  • Check all variable placeholders are filled in correctly
  • Monitor delivery logs via Messaging → WhatsApp → Logs
