API Integrations Documentation

Complete guide on how to configure SMS and WhatsApp gateways on Greyteeks.

SMS API Providers

Africa's Talking provides robust SMS networks across Africa.

  1. Create an account on the Africa's Talking portal.
  2. Get your App Username: Ensure you create an "App" and use the exact App Username, not your login email.
  3. Generate an API Key: Go to Settings > API Key and generate your key. Keep this secure.
  4. Sender ID: Register an alphanumeric Sender ID. E.g., `GREYTEEKS`.
  5. Dashboard Setup: Navigate to SMS > Add Provider. Select "Africa's Talking", input the API Key, your App Username, and your approved Sender ID.

WhatsApp API Providers

Direct connection to Meta's infrastructure for zero-markup messaging.

Step 1: Create a Meta App
  1. Go to Meta for Developers.
  2. Create App > Business > Set up WhatsApp product.
Step 2: Generate Access Token
  1. Do NOT use the temporary token provided on the dashboard.
  2. Go to Business Settings > System Users.
  3. Generate a token for a System User and assign it the whatsapp_business_messaging permission.
Step 3: Extract IDs
  1. Phone Number ID: Found on the WhatsApp > Getting Started page. This uniquely identifies the sending number.
  2. WhatsApp Business Account ID (WABA ID): Also found on the Getting Started page.

  1. Access Token (API Key): Generated from Infobip's developer dashboard.
  2. Base URL: The assigned regional URL (e.g., `xyz.api.infobip.com`).
  3. Infobip Sender: The official WhatsApp number approved inside Infobip.
Crucial Note on WhatsApp Templates

By Meta policy, all brand-initiated outbound WhatsApp messages must strictly be approved Templates. The contents of templates sent through Greyteeks must match your Meta Console approval character-for-character to avoid failure.
